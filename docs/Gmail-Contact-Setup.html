Setup Gmail — formular contact

Ca formularul să trimită pe mihail.mihai2001@gmail.com (necesar înainte de Google Ads).

Important: Nu folosi parola normală de Gmail. Ai nevoie de App Password (16 caractere).

1. Creează App Password (2 minute)

  1. Deschide Google Account → Security
  2. Activează 2-Step Verification (dacă nu e deja)
  3. Mergi la App passwords
  4. App name: SitePerHour → Generate
  5. Copiază parola de 16 caractere (ex: abcd efgh ijkl mnop)

2. Variabile pe Vercel (production)

Vercel → Project SitePerHour → Settings → Environment Variables → adaugă:

NameValue
GMAIL_USERmihail.mihai2001@gmail.com
GMAIL_APP_PASSWORDparola App Password (fără spații sau cu spații — ambele merge)
CONTACT_TOmihail.mihai2001@gmail.com (unde primești mesajele)

Environments: Production (+ Preview dacă vrei).

Apoi: Deployments → Redeploy (sau push pe main).

3. Local (opțional)

  1. Copiază .env.example → .env.local
  2. Pune App Password-ul
  3. bun run dev → testează formularul pe /ro#contact

4. Test rapid

  1. Deschide siteperhour.com/ro#contact
  2. Trimite un mesaj de test
  3. Verifică inbox + spam pe Gmail
  4. Reply din Gmail trebuie să meargă la emailul clientului (Reply-To)
Codul e gata: /api/contact + /api/quote folosesc Nodemailer → Gmail. Dacă lipsește App Password, API returnează 503 „Email service not configured”.

5. Dacă nu merge

  • „Username and Password not accepted” → App Password greșit sau 2FA off
  • Mesaj nu apare → verifică Spam / Promotions
  • Vercel logs: Project → Deployments → Functions → /api/contact
  • Nu pune App Password în Git / chat — doar în Vercel / .env.local
