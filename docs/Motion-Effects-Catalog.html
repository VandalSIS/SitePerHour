Catalog Animații & Efecte

Lista practică de motion bun pentru SitePerHour — ce merită, unde, cu ce librărie. Nu tot ce există pe Awwwards — doar ce se potrivește unui site de agenție dark, rapid, RO.

v1.0 13 septembrie 2026 Complement la Inspiration-Scroll-Motion
Legendă prioritate: MUST = impact mare, fă acum · GOOD = merită în Faza B/D · LATER = opțional · SKIP = evită (generic / greu / rău pe mobil)

1. Tipografie & headline motion

Efect Ce face Unde pe site Tech
Word / line reveal Cuvintele sau rândurile apar unul câte unul (urcă din jos) Hero, titluri secțiuni Framer Motion MUST
Split text stagger Fiecare literă/cuvânt cu delay scurt Hero load, CTA titles Framer Motion / GSAP SplitText MUST
Mask reveal Textul „iese” dintr-o mască (clip-path) Titluri mari, About CSS + Motion / GSAP GOOD
Kinetic type on scroll Titlul se mișcă / scale / fade la scroll Hero exit, section headers useScroll + useTransform MUST
Text swap (chapter) Textul se schimbă în aceeași scenă (ca dixi.md) Benefits / Process GSAP ScrollTrigger GOOD
Typewriter Scrie literă cu literă — — SKIP
Glitch text Distorsiune / RGB split — — SKIP

2. Scroll & scrollytelling

Efect Ce face Unde pe site Tech
Smooth scroll (Lenis) Scroll „buttery”, ca pe site-uri premium Tot site-ul (desktop) Lenis MUST
Pinned section Secțiunea rămâne lipită cât rulează animația Benefits, Process (stil dixi) GSAP ScrollTrigger GOOD
Scroll scrub Animația urmărește progresul scroll-ului Pinned scenes, parallax GSAP / Framer useScroll GOOD
Scroll progress bar Bară verticală / top care arată progresul Scenă pinned sau pagină CSS + scrollY GOOD
Parallax layers Fundal / vizual se mișcă mai lent decât textul Hero, Projects Framer Motion MUST
Stagger on enter Cardurile apar unul după altul la scroll Services, Projects, Tech Framer whileInView MUST
Horizontal scroll section Scroll vertical → galerie laterală Projects / case studies GSAP / CSS scroll-timeline LATER
Fullpage snap Fiecare scroll = o pagină întreagă — fullPage.js SKIP
Heavy scroll hijacking Blochează scroll-ul agresiv — — SKIP

7. Stack recomandat (pe scurt)

Librărie Pentru Când

Lenis Smooth scroll Următorul MUST
GSAP + ScrollTrigger Pinned scrollytelling (dixi-style) Faza D / Process
@react-three/fiber Globe / 3D hero Faza D, desktop only
CSS only Hover, marquee, grain, underline Mereu — 0 bundle

8. Shortlist SitePerHour (ordine de implementare)

  1. Lenis — smooth scroll pe tot site-ul
  2. Stagger cards — Services + Projects la scroll
  3. Hero kinetic — deja început; fine-tune diacritice + parallax
  4. Section headers — word reveal editorial (Space Grotesk)
  5. Pinned Benefits — scrollytelling tip dixi.md (text swap + vizual)
  6. Magnetic CTA + card tilt — polish desktop
  7. Three.js globe — hero desktop only
  8. Horizontal projects — opțional, later
Regulă de aur: max 1–2 efecte „grele” pe pagină (pin SAU 3D, nu ambele pe mobil). Mereu prefers-reduced-motion → version statică. Dacă un efect nu se înțelege în 1 secundă, e zgomot — taie-l.
